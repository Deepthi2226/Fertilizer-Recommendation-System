# 🌿 Smart Fertilizer Recommendation System

## 📖 Overview
The **Smart Fertilizer Recommendation System** is a machine learning–based web application built using **Flask**.  
It helps farmers and agricultural experts determine the most suitable fertilizer based on soil type, crop type, and other environmental conditions.  
The project integrates predictive modeling with an interactive web interface for efficient, real-world usage.

---

## 🚀 Features
- 🧠 Machine Learning model for fertilizer prediction  
- 🌱 Supports multiple soil and crop types  
- 💻 User-friendly Flask web interface  
- 📊 Real-time fertilizer recommendation output  
- 🔗 Ready for integration with IoT sensors for automated input
